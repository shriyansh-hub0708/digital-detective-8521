## 4. What Is a GitHub Repository?

A GitHub repository is a place where a project's files, documentation and version history can be stored online. A public repository allows other people to view the project and collaborate when they have the required permissions.

## 5. Why Organise Work into Separate Mission Folders?

Separate folders make the project organised and easier to understand. They help us identify which information belongs to which mission, making files easier to locate, update and maintain.
