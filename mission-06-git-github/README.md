## 3. Commands / tools used

| Command | Purpose |
|---|---|
| `git status` | Checks the current repository status. |
| `git add` | Stages selected changes. |
| `git commit` | Saves staged changes as a commit. |
| `git log --oneline` | Displays recent commit history. |
| `git branch` | Creates or lists branches. |
| `git switch` | Switches between branches. |
| `git push` | Publishes commits to GitHub. |
| `git init` | Initialises a Git repository. |
| `git pull` | Retrieves and integrates remote changes. |

Other commands used: `touch`, `echo`, and `cat`.

Tool used: GitHub website for creating and reviewing a Pull Request.

## 4. My understanding

Git is a version control system that tracks changes in a project. GitHub is an online platform used to host Git repositories and collaborate.

Staging means selecting changes that should be included in the next commit, while committing saves those staged changes in the local repository.

A branch provides an independent line of development. A Pull Request allows developers to propose and review changes before merging them into another branch.
