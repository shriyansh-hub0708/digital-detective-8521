## Task 4.2 — Compiler vs Interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When translation/execution happens | Translates source code before execution | Executes instructions at runtime |
| Typical output | Often produces machine code or an executable | Executes the program through the interpreter |
| One example | C (using GCC/Clang) | Python |
| One advantage | Compiled programs can run efficiently | Convenient for testing and running programs |

### Explanation

A compiler translates the source code into another form, often machine code, before the program is executed. An interpreter reads and executes the program's instructions at runtime. C commonly uses a compiler, while Python is commonly run using an interpreter. However, some language implementations, including Python's CPython, combine techniques such as bytecode compilation and interpretation.
