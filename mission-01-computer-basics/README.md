# Mission 1 — Computer Basics

## Task 1.1 — Typing and Saving a Document Using VS Code

### Activity

Typing and saving the README file of my Digital Detective project using Visual Studio Code on my MacBook.

### IPOS Table

| Stage | What happens in my example? | Hardware / Component |
|---|---|---|
| **Input** | I enter text into VS Code using my MacBook keyboard. Each keystroke is sent to the computer as input data. | Keyboard |
| **Processing** | The CPU processes the instructions and the computer updates the document. RAM temporarily holds the data and instructions being used by VS Code. | CPU and RAM |
| **Output** | After processing the input, the typed text appears on my MacBook screen. This allows me to view and check the document. | Built-in display |
| **Storage** | When I press Command + S, VS Code saves the document. The first time, I select the filename and folder. The file is then stored on my MacBook's internal SSD. | SSD (Macintosh HD) |

### How the Activity Moves Through IPOS

When I type text into VS Code, the keyboard sends my keystrokes to the computer. The CPU processes the instructions while RAM temporarily holds the information being used. The result is displayed on the screen so I can view the document. Finally, when I save the file, it is stored on the internal SSD of my MacBook. This allows me to open and edit the document again later.

## Task 1.3 — Computer Systems Around Me

Computer-based systems are present in many everyday objects. They receive inputs, process information and produce outputs to perform specific tasks.

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| Smart TV | To watch television programmes and stream online content. | Remote control commands | Visual and audio output through the screen and speakers. |
| Traffic Signal | To control the movement of vehicles and pedestrians. | Timer instructions | Red, yellow and green lights. |
| Microwave Oven | To heat or cook food. | Cooking time and Start button | Food gets heated and the internal light turns on. | 

### Difficulties Faced

One of the difficulties I faced during this mission was identifying the different hardware components of my MacBook and understanding their functions. I also found it challenging to understand how everyday computer-based systems, such as traffic signals and microwave ovens, work behind the scenes. This mission helped me recognise that computers are present in many devices around us, not just laptops and mobile phones.

### What I Understood

The most important thing I learned from this mission was understanding my MacBook, its hardware components and the software that makes it work. I also discovered that many devices I use in everyday life, such as smart TVs, traffic signals and microwave ovens, are computer-based systems even though I never really thought of them as computers before.

### Tools and Commands Used

- **MacBook:** Used to explore and identify the computer's hardware components.
- **Visual Studio Code (VS Code):** Used to write, edit and preview the Markdown README.
- **Commands:** No Terminal commands were required to complete the three tasks in this mission.
