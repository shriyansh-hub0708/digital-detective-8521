# Digital Detective: How Does My Computer Work?

## Project Overview

This project is about exploring how a computer works behind the screen. It focuses on understanding how a computer takes input, processes information and produces output. It also explores how hardware, software, operating systems and networks work together to make a computer function.

## Why Am I Doing This Project?

Whenever I use a computer, I often wonder how this machine actually works and performs its tasks so efficiently. I have always been curious about how components like the monitor, keyboard and CPU work together so quickly and smoothly.

As a first-year Computer Science student, I believe understanding the fundamentals of computers is important. Through this project, I explored what happens behind the screen, strengthened my basic computer knowledge and understood the technology I use every day.

## Topics Explored

- Computer fundamentals: input, processing and output
- Hardware and software
- Terminal commands and file management
- Operating systems, processes and file permissions
- Compilers and interpreters
- Number systems and data representation
- Git, GitHub, branches and pull requests
- Computer networks: LAN, MAN and WAN
- DNS, routers, protocols and client-server architecture
- How computers communicate over a network
