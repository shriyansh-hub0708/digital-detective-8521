# Digital Dectective: How Does My Computer Works?

## Project Overview

This project is about exploring how a computer works behind the screen. It focuses on understanding how a computer takes input, processes information and produces output. It also explores how hardware, software, operating systems and networks work together to make a computer function.

## Why Am I Doing This Project?

Whenever I use a computer, I often wonder how this machine actually works and performs it's tasks so efficiently. I have always been curious about how components like the monitor, keyboard and CPU work together so quickly and smoothly.

As a first-year Computer Science student, I believe understanding the fundamentals of computers is important. Through this project, I want to explore what happens behind the screen, strengthen my basic computer knowledge and understand the technology I use every day.
